= Exercises
:toc: left
:toclevels: 3

The exercises on the installed `demo` database, the PostgreSQL demonstration database (https://postgrespro.com/community/demodb[Airlines]), in its `bookings` schema: a section for each table and view, with a section for each level, and, at the end, a section for the schema as a whole.
Each exercise poses a problem; its answer, and what the installed data gives back, are in the `.sql` file.
The data is the `3m` edition, three months of flights from 2025-10-01, and the database's today, `bookings.now()`, is 2025-12-01; the views read the names in the language `bookings.lang()` returns, `en`.
A day or a month is a UTC one, unless an exercise says it is an airport's local one: a bound on a `timestamptz` is written `TIMESTAMPTZ '2025-10-01 00:00:00+00'`, and a day or a month is taken `AT TIME ZONE 'UTC'`, so that the answer does not depend on the session's time zone, which psql and a JDBC connection set differently.

Run a file as a whole:

[source,sh]
----
docker exec -i postgresql-demodb psql -U postgres -d demo < src/test/sql-exercises/<section>/<NN>_<level>.sql
----

[[DEMODB_AIRPLANES_DATA_A_02]]
==== DEMODB_AIRPLANES_DATA_A_02: the airplanes by the flights they fly

Count the flights each airplane flies, `0` for one that flies none: a flight's airplane is the one of the route's row valid at the flight's scheduled departure.
Show the code, the English name and the count, the most first; airplanes with the same count are ordered by `airplane_code`.
Two outer joins, the second on a range containment (`@>`), and a group.

.`airplanes_data/03_advanced.sql`, DEMODB_AIRPLANES_DATA_A_02
[%collapsible]
====
[source,sql]
----
SELECT a.airplane_code, a.model ->> 'en' AS model, COUNT(f.flight_id) AS flights
FROM airplanes_data a
         LEFT JOIN routes r ON r.airplane_code = a.airplane_code
         LEFT JOIN flights f ON f.route_no = r.route_no AND r.validity @> f.scheduled_departure
GROUP BY a.airplane_code, a.model
ORDER BY flights DESC, a.airplane_code
----

==== DEMODB_AIRPLANES_A_02: the airplanes ranked by speed, ties sharing a rank

==== DEMODB_AIRPORTS_DATA_A_01: the cities with more than one airport

Group the airports by city and country, in English, and keep the cities with more than one.

[%collapsible]
====
[source,sql]

       country ->> 'en'                                     AS country,
       STRING_AGG(airport_code, ', ' ORDER BY airport_code) AS airports,
       COUNT(*)                                             AS count
FROM airports_data

ORDER BY count DESC, city, country
LIMIT 10

[[DEMODB_BOARDING_PASSES_A_01]]
==== DEMODB_BOARDING_PASSES_A_01: the passengers of the first day seated in other fare conditions than they paid

For the flights scheduled on 2025-10-01, find the boarding passes whose seat's `fare_conditions`, on the flight's airplane, differs from the segment's.
Count them, and count them per direction: upgraded, a seat of better fare conditions than paid for, and downgraded.

.`boarding_passes/03_advanced.sql`, DEMODB_BOARDING_PASSES_A_01
[%collapsible]
====
[source,sql]
----

       COUNT(*) FILTER (WHERE rank.seat > rank.paid) AS upgraded,
       COUNT(*) FILTER (WHERE rank.seat < rank.paid) AS downgraded
FROM boarding_passes bp
         JOIN segments s ON s.ticket_no = bp.ticket_no AND s.flight_id = bp.flight_id
         JOIN flights f ON f.flight_id = bp.flight_id
         JOIN routes r ON r.route_no = f.route_no AND r.validity @> f.scheduled_departure
         JOIN seats st ON st.airplane_code = r.airplane_code AND st.seat_no = bp.seat_no
         CROSS JOIN LATERAL (SELECT ARRAY_POSITION(ARRAY ['Economy', 'Comfort', 'Business'],
                                                   st.fare_conditions) AS seat,
                                    ARRAY_POSITION(ARRAY ['Economy', 'Comfort', 'Business'],
                                                   s.fare_conditions)  AS paid) rank
WHERE f.scheduled_departure >= TIMESTAMPTZ '2025-10-01 00:00:00+00'
  AND f.scheduled_departure < TIMESTAMPTZ '2025-10-02 00:00:00+00'
