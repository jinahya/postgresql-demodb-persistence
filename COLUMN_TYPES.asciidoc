Every column type the tables of `bookings` declare, grouped by the sections of link:{data-types}[Data Types] in the
PostgreSQL 18 documentation. Each type is listed as the catalog (`pg_attribute`, `format_type`) reports it, and each
column as `table.column`; 45 columns of 9 tables in all. The views are left out; see <<views>>.

The Java type is the type of the attribute which maps the column in the `Mapped*` classes, the wrapper types, never
a primitive, and `java.time` for the date/time types. A column whose type is not the usual one for its declared
type is named in the section's notes; each foreign-key column has its key's type.

No column is `smallint`, `bigint`, `real`, `double precision`, a `serial`, `money`, `character varying`, `bytea`,
`date`, `timestamp without time zone`, `time with time zone`, an enumerated type, a geometric type other than
`point`, a network address type, a bit string, a text search type, `uuid`, `xml`, `json`, a composite type, a range
type other than `tstzrange`, a multirange or a domain.

== Character Types

See link:{docs}/datatype-character.html[Character Types].

`character(n)` is blank-padded to its length, but every code here fills it: the airport and airplane codes are
three characters, and a booking's `book_ref` six. `text` has no length.

`seats.fare_conditions` and `segments.fare_conditions` a `MappedSeat.FareConditions`, each checked against a list of

== Date/Time Types

See link:{docs}/datatype-datetime.html[Date/Time Types].

`timestamp with time zone` holds an instant, which the server prints in the session's time zone, and is an
`Instant`. `time without time zone` is a `LocalTime`. `interval` is a `Duration`, which Hibernate ORM binds and reads
as an interval for its `@JdbcTypeCode(SqlTypes.INTERVAL_SECOND)`; a `Duration` has no months, and
`routes.duration` holds hours and minutes.

== Range Types

See link:{docs}/rangetypes.html[Range Types].

`routes.validity` is the period a route is valid, `[lower,upper)`; with `route_no` it is the key of `routes`, which
has no primary key but the exclusion constraint `routes_route_no_validity_excl`. It is an `Instant[]` of its two
bounds through `RouteId.ValidityConverter`, which reads and writes the range's text.

[[views]]
== Views

A view's columns take the types of the expressions which select them:

* `airplanes.model`, and `airports.airport_name`, `city` and `country`, are `text`: each is the name in the
  language of `bookings.lang()` (`jsonb ->> lang()`), which the session setting `bookings.lang` chooses (`en` by
  default).
* `timetable`'s four `*_local` columns are `timestamp without time zone`, the instants `AT TIME ZONE` the airport's
  `timezone`; they are `LocalDateTime`s.
* Every other view column is a table column, and has its type.
